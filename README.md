# Tech Roundup Guide: One-Way Discreet Messaging for Friends

# Receiving: 
1. If you know **where** to look
2. If you know **when** to look
3. If you have the **key**...

then you can view messages sent by your friends. 

# Sending:
**One Time Setup** (or whenever you want to change your admin key)
1. Open the sealer.html in a browser to set your admin key
2. Copy the output into the "_d" line in the index.html (make sure it's live)

**Sending Messages**
1. Enter your admin key (in the **right place**) to open the admin console and craft your messages to the sender 
2. Copy the new index.html to your live site.
