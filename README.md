# Tech Roundup Guide
Receiving: If you know where to look; when to look; and have the right key, you can view messages sent by your friends.
Sending: You need the setup.html to set your key, and need to replace the "_d" thing in the index.html with that key. Use that to enter the admin password (in the right place) to open the console and craft your messages. Once it's ready, copy the new index.html and update the Github Pages.
