# Tech Roundup Guide
**Receiving**: This side is pretty straightforward, and neat. 

If you know where to look; when to look; and have the right key, you can view messages sent by your friends. 

**Sending**: This one's a bit more complicated, because we want to keep things self-contained and in the browser.

1. First, you need the setup.html to set your admin key.
2. Replace the output from the setup.html in the "_d" line in the index.html. 
3. Enter your admin key (in the right place) to open the admin console and craft your messages to the sender. 
4. Copy the new index.html to Github Pages so it becomes the live site.
