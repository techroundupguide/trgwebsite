# Tech Roundup Guide
**Receiving**: If you know where to look; when to look; and have the right key, you can view messages sent by your friends.

**Sending**: You need the setup.html to set your admin key, and need to replace the output from the setup.html in the "_d" line in the index.html. 

Once that's on the live site, you'll enter that admin key (in the right place) to open the console and craft your messages to the sender. 

Once that's done, copy the new index.html to Github Pages so it becomes the live site.
